# Правило №11: Компактные отступы для десктопа

Все списочные CRUD-страницы (Роли, Пользователи, Тенанты, Разделы и т.д.) **ОБЯЗАТЕЛЬНО** должны использовать единый стандарт компактных отступов и типографики. Это обеспечивает максимальную плотность информации на экране, что критически важно для десктопных ERP-интерфейсов, где пользователь работает с большими объемами данных.

---

### 1. Обоснование (Почему это важно)

1. **Плотность информации (Information Density):** В бизнес-приложениях пользователь должен видеть как можно больше данных без скролла. Избыточные отступы (`py-8`, `mb-6`) «съедают» полезное пространство экрана.
2. **Единообразие UX:** Когда все страницы приложения имеют одинаковую структуру (отступы, размеры шрифтов, расположение элементов), пользователь не тратит когнитивный ресурс на адаптацию при переходе между разделами.
3. **Профессиональный вид:** Компактные отступы — это визуальный маркер «серьезного» корпоративного инструмента. Избыточные «воздушные» интерфейсы характерны для лендингов и маркетинговых сайтов, но не для рабочих ERP-систем.
4. **Эффективность работы:** Меньше скролла — быстрее навигация. Пользователь за одну сессию успевает обработать больше записей.

---

### 2. Обязательные требования к реализации

#### 2.1. Контейнер страницы
Корневой контейнер страницы **ОБЯЗАТЕЛЬНО** должен иметь классы:
```tsx
<div className="container mx-auto px-4 py-3">
```
* `container` — стандартная ширина контейнера из Tailwind.
* `mx-auto` — центрирование по горизонтали.
* `px-4` — горизонтальный padding (16px).
* `py-3` — вертикальный padding (12px). **Критически важно:** не `py-6` или `py-8`!

#### 2.2. Заголовок страницы
Заголовок (H1) **ОБЯЗАТЕЛЬНО** должен иметь классы:
```tsx
<h1 className="text-xl font-bold">Роли</h1>
```
* `text-xl` — размер шрифта 20px (не `text-2xl` или `text-3xl` — это слишком крупно для заголовка раздела).
* `font-bold` — жирное начертание для визуального выделения.

#### 2.3. Блок заголовка (Header Block)
Контейнер, объединяющий заголовок и кнопки действий (например, «Создать»), **ОБЯЗАТЕЛЬНО** должен иметь классы:
```tsx
<div className="flex flex-col md:flex-row justify-between items-start md:items-center gap-2 mb-2">
```
* `flex flex-col md:flex-row` — адаптивная верстка: на мобильных колонкой, на десктопе — в строку.
* `justify-between` — заголовок слева, кнопки справа.
* `items-start md:items-center` — выравнивание по верху на мобильных, по центру на десктопе.
* `gap-2` — компактный отступ между элементами (8px).
* `mb-2` — нижний отступ до следующего блока (8px). **Не `mb-4` или `mb-6`!**

#### 2.4. Счётчик записей
Под заголовком **ОБЯЗАТЕЛЬНО** должен отображаться счетчик общего количества записей:
```tsx
<p className="text-xs text-muted-foreground mt-0.5">Всего: {total}</p>
```
* `text-xs` — мелкий шрифт (12px), чтобы не конкурировать с заголовком.
* `text-muted-foreground` — приглушенный цвет для второстепенной информации.
* `mt-0.5` — минимальный отступ сверху (2px), чтобы «приклеить» к заголовку.

### 3. Примеры кода

#### ✅ ПРАВИЛЬНО: Полная структура шапки страницы

```tsx
import { Button } from "@/components/ui/button";
import { Plus } from "lucide-react";

export const RolesPage = () => {
  const { data } = useReadRolesRolesGet({ skip: 0, limit: 10 });
  const total = data?.data?.total || 0;

  return (
    <div className="container mx-auto px-4 py-3">
      {/* ✅ БЛОК ЗАГОЛОВКА С КОМПАКТНЫМИ ОТСТУПАМИ */}
      <div className="flex flex-col md:flex-row justify-between items-start md:items-center gap-2 mb-2">
        <div>
          {/* ✅ ЗАГОЛОВОК СТРАНИЦЫ */}
          <h1 className="text-xl font-bold">Роли</h1>
          {/* ✅ СЧЁТЧИК ЗАПИСЕЙ */}
          <p className="text-xs text-muted-foreground mt-0.5">
            Всего: {total}
          </p>
        </div>

        {/* ✅ КНОПКА ДЕЙСТВИЯ */}
        <Button onClick={() => setIsCreateOpen(true)}>
          <Plus className="mr-2 h-4 w-4" />
          Создать роль
        </Button>
      </div>

      {/* Поиск (Правило №12) */}
      <form onSubmit={handleSearch} className="flex gap-2 mb-2">
        {/* ... */}
      </form>

      {/* Таблица (Правило №13) */}
      <div className="rounded-md border bg-card">
        <Table>...</Table>
      </div>
    </div>
  );
};
```

#### ❌ НЕПРАВИЛЬНО: Избыточные отступы (Антипаттерн)

```tsx
// ❌ ГРУБОЕ НАРУШЕНИЕ ПРАВИЛА №11
<div className="container mx-auto px-8 py-12"> {/* ❌ Слишком большие отступы */}
  <div className="mb-8"> {/* ❌ Огромный отступ снизу */}
    <h1 className="text-3xl font-extrabold mb-4">Роли</h1> {/* ❌ Слишком крупный заголовок */}
    <p className="text-lg text-gray-500">
      Всего записей: {total}
    </p>
  </div>
  
  <Button className="mb-6">Создать роль</Button> {/* ❌ Лишний отступ */}
</div>
```
*Почему это плохо:* Страница занимает в 2-3 раза больше места, чем необходимо. Пользователь видит меньше данных, вынужден больше скроллить. Интерфейс выглядит «раздутым» и непрофессионально.

#### ❌ НЕПРАВИЛЬНО: Отсутствие счётчика записей

```tsx
// ❌ ОШИБКА: Пользователь не видит общее количество записей
<div className="flex justify-between items-center mb-4">
  <h1 className="text-2xl font-bold">Роли</h1>
  <Button>Создать роль</Button>
  {/* ❌ Отсутствует <p>Всего: {total}</p> */}
</div>
```
*Почему это плохо:* Пользователь не понимает масштаб данных. Если в системе 5000 ролей, а на странице видно 10, он должен догадываться об этом по пагинации. Счётчик дает мгновенную ориентацию.

#### ❌ НЕПРАВИЛЬНО: Отсутствие адаптивности

```tsx
// ❌ ОШИБКА: На мобильных устройствах кнопка и заголовок будут перекрываться
<div className="flex justify-between items-center mb-4">
  <h1 className="text-xl font-bold">Роли</h1>
  <Button>Создать роль</Button>
</div>
```
*Почему это плохо:* На экране шириной 320px (старые смартфоны) длинный заголовок «Администраторы системы» и кнопка «Создать роль» не поместятся в одну строку и будут обрезаны или перекроют друг друга.

### 4. Нюансы и лучшие практики

#### 4.1. Иконка рядом с кнопкой
Для улучшения визуального восприятия **рекомендуется** добавлять иконку в основную кнопку действия:
```tsx
<Button>
  <Plus className="mr-2 h-4 w-4" />
  Создать роль
</Button>
```
Иконка должна быть размером `h-4 w-4` (16px) с правым отступом `mr-2`.

#### 4.2. Группировка действий
Если на странице несколько кнопок действий (например, «Создать», «Импорт», «Экспорт»), их **ОБЯЗАТЕЛЬНО** нужно обернуть в контейнер с `flex gap-2`:
```tsx
<div className="flex gap-2">
  <Button>
    <Plus className="mr-2 h-4 w-4" />
    Создать
  </Button>
  <Button variant="outline">
    <Upload className="mr-2 h-4 w-4" />
    Импорт
  </Button>
</div>
```

#### 4.3. Форматирование числа записей
Если количество записей большое, **рекомендуется** использовать форматирование с разделителями тысяч:
```tsx
<p className="text-xs text-muted-foreground mt-0.5">
  Всего: {total.toLocaleString("ru-RU")}
</p>
// Выведет: "Всего: 1 234" вместо "Всего: 1234"
```

#### 4.4. Связь с Правилом №13
Отступ `mb-2` блока заголовка — это расстояние до следующего блока (поиска или таблицы). Сам блок таблицы имеет свои отступы через `rounded-md border bg-card` (Правило №13). Важно не дублировать отступы: если у заголовка `mb-2`, у таблицы не должно быть дополнительного `mt-2`.

#### 4.5. Хлебные крошки (Breadcrumbs)
Если в приложении используется навигация через хлебные крошки, они должны располагаться **над** блоком заголовка с минимальным отступом `mb-1`:
```tsx
<div className="container mx-auto px-4 py-3">
  {/* Хлебные крошки */}
  <Breadcrumb className="mb-1">
    <BreadcrumbList>
      <BreadcrumbItem>
        <BreadcrumbLink href="/">Главная</BreadcrumbLink>
      </BreadcrumbItem>
      <BreadcrumbSeparator />
      <BreadcrumbItem>
        <BreadcrumbPage>Роли</BreadcrumbPage>
      </BreadcrumbItem>
    </BreadcrumbList>
  </Breadcrumb>

  {/* Блок заголовка */}
  <div className="flex flex-col md:flex-row justify-between items-start md:items-center gap-2 mb-2">
    {/* ... */}
  </div>
</div>
```

### 5. Чек-лист для разработчика

При создании или рефакторинге любой списочной страницы проверьте:

- [ ] Используется ли контейнер `container mx-auto px-4 py-3`?
- [ ] Имеет ли заголовок классы `text-xl font-bold`?
- [ ] Обёрнут ли блок заголовка в `flex flex-col md:flex-row justify-between items-start md:items-center gap-2 mb-2`?
- [ ] Отображается ли счётчик записей `<p className="text-xs text-muted-foreground mt-0.5">Всего: {total}</p>`?
- [ ] Отсутствуют ли избыточные отступы (`py-6`, `py-8`, `mb-6`, `text-3xl`)?
- [ ] Есть ли иконка в основной кнопке действия?
- [ ] Адаптирована ли верстка для мобильных устройств (`flex-col` vs `flex-row`)?
- [ ] Форматируется ли число записей через `toLocaleString("ru-RU")` (если ожидаются большие значения)?

Следование этому правилу гарантирует, что все списочные страницы в Cool ERP будут выглядеть профессионально, компактно и единообразно, обеспечивая максимальную эффективность работы пользователя с данными.
