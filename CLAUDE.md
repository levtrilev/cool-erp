# Правила разработки Cool ERP для ИИ
- Язык бэкенда: Python 3.12. Использовать async/await везде.
- Фреймворки: FastAPI, SQLAlchemy 2.0 (async), Pydantic v2.
- Фронтенд: React, TypeScript, Vite, TanStack Query.
- Любой запрос к БД (кроме супер-админа) ОБЯЗАТЕЛЬНО должен фильтроваться по `tenant_id`.
- Перед написанием нового кода всегда проверяй папку `doc` на наличие ТЗ по этому модулю.
- Все новые эндпоинты должны быть типизированы (Pydantic) и сгенерированы через Orval для фронтенда.
