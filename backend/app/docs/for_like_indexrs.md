## Оптимизация PostgreSQL 
(Индексы для ILIKE)Обычный B-Tree индекс в PostgreSQL не работает с запросами вида LIKE '%текст%' (когда процент стоит в начале). При объеме данных более 100 000 записей поиск без индекса приведет к полному сканированию таблицы (Full Table Scan) и сильным задержкам.Для ускорения регистронезависимого поиска по подстроке в PostgreSQL используется расширение pg_trgm (триграммы) и тип индекса GIN.SQL-миграция (Alembic или прямой SQL-запрос):

# Перед запуском кода выполните этот SQL-запрос в вашей базе данных (или добавьте в миграцию):

-- 1. Включаем расширение для работы с триграммами (нужны права суперпользователя базы)
CREATE EXTENSION IF NOT EXISTS pg_trgm;

-- 2. Создаем GIN-индекс для вашей таблицы (замените users на имя вашей таблицы)
CREATE INDEX IF NOT EXISTS idx_users_name_trgm ON users USING gin (name gin_trgm_ops);
